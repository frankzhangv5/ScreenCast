# 手机投屏桌面程序

一个基于Qt6开发的手机投屏桌面应用程序，具有现代化的UI设计和无边框窗口效果。

## 功能特性

- 🎨 **现代化UI设计**: 使用QtTheme主题配色，类似PyCharm的启动页
- 📱 **设备检测**: 自动检测连接的Android/iOS设备
- 🖥️ **屏幕镜像**: 点击开始镜像按钮显示设备屏幕画面
- 🚀 **无边框窗口**: 应用启动后显示无边框主界面
- 🔄 **实时刷新**: 定时检测设备连接状态

## 界面说明

### 启动页
- 应用启动时显示3秒的无边框启动页
- 渐变背景和应用程序logo
- 显示"正在启动..."提示

### 主界面
- **状态标签**: 显示设备检测状态
- **设备列表**: 显示连接的设备信息
  - 设备类型图标 (Android: 🤖, iOS: 🍎)
  - 设备名称和序列号
  - 开始镜像按钮
- **刷新按钮**: 手动刷新设备列表

### 镜像窗口
- 600x800固定大小的窗口
- 黑色背景显示设备镜像画面
- 标题栏显示设备名称

## 技术栈

- **Qt 6.9.1**: 跨平台C++应用程序框架
- **C++17**: 现代C++标准
- **QtTheme**: 主题配色系统
- **QSS样式表**: 界面样式定制

## 编译运行

### 前提条件
- Qt 6.9.1 或更高版本
- MinGW 编译器
- Windows 操作系统

### 编译命令
```bash
# 创建并进入构建目录
mkdir build
cd build

# 生成Makefile并编译
qmake ..
make
```

### 运行程序
```bash
release\Mirror.exe
```

> **注意**: 为了保持项目根目录的整洁，所有构建操作都应该在 `build` 目录中进行，不要在根目录直接构建。

## 使用说明

1. 连接Android/iOS设备到电脑
2. 确保设备已开启USB调试模式
3. 运行应用程序
4. 应用程序会自动检测连接的设备
5. 点击设备列表中的"开始镜像"按钮
6. 新窗口将显示设备屏幕画面

## 自定义配置

### 修改主题
编辑 `theme/Flat/Dark/Green/LightGreen.qss` 文件来自定义应用程序样式。

### 调整窗口大小
在 `MainWindow.cpp` 中修改:
```cpp
// 主窗口大小
setGeometry(x, y, 400, 300);

// 镜像窗口大小
mirrorWindow->setFixedSize(600, 800);
```

### 设备检测间隔
修改设备检查定时器间隔:
```cpp
m_deviceCheckTimer->start(2000); // 每2秒检查一次
```

## 注意事项

- 目前使用模拟设备数据进行演示
- 实际设备检测需要集成ADB或其他设备管理库
- 镜像功能目前为模拟显示，需要实现实际的屏幕捕获和传输
